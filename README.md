# Revenge of the Orange

In *Chain Reaction*, by BenW, an orange tile had to escape the terrifying advance of the musical tide of explosions. Enough fleeing. Time for revenge.

At each level, the hero tile has to use the chain reactions to blow up all the targets at the same time, by shifting the tiles around it, or full rows and columns.

Made in 48 hours for **MiniLD #5** (November 2008).

It runs on an early version of [evöL](https://github.com/Castux/evol), included here (`evol.lua`, `evolcore.c`). It was imported in 2026 from the archive published on my old site; there was no version control history.

The original builds (2008–2010) are in the [releases](../../releases).
